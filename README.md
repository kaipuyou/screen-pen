# 屏幕笔

Windows 原生屏幕标注与截图工具。它会在当前鼠标所在的显示器上创建透明覆盖层，直接叠加在浏览器、CAD、Office、PDF 或任何项目页面上，不会替换成白板。

## 使用方法

1. 使用 Visual Studio 2022（安装“.NET 桌面开发”工作负载）打开 `ScreenAnnotator.sln`。
2. 编译并运行 `ScreenAnnotator` 项目。
3. 首次启动会显示《使用提示与说明书》，关闭即可；之后可从主窗口或系统托盘再次打开。
4. 按 `F2` 开始屏幕笔，选择工具后直接在屏幕上画线、圈选和写字。
5. 按 `F3` 进入类似微信的截图状态：拖出选区后点击 `✓`，截图只复制到剪贴板；屏幕笔自动结束并把焦点还给刚才使用的程序。点击 `×` 或按 `Esc` 取消。到微信、文档、画图等位置按 `Ctrl+V` 粘贴。
6. 按 `Ctrl+S` 保存可编辑 JSON 项目；按 `Esc` 暂停并释放桌面，不会清空标注。

## 快捷键

`F2` 开始/再次开始屏幕笔；`F1` 重置并清除全部标注；`F3` 区域截图；`Esc` 暂停；`Ctrl+Z` 撤销；`Ctrl+Y` 重做；`Ctrl+S` 保存项目；`Tab` 显示/隐藏工具栏。

工具栏内提供“隐藏 Tab”按钮，点击即可隐藏；隐藏后按 `Tab` 恢复。

截图点击绿色 `✓` 后，本次屏幕笔结束，标注内容不会清空；屏幕笔会完全释放桌面、任务栏和其他软件。再次按 `F2` 会恢复原标注并重新开始使用。只有按 `F1` 或托盘里的“重置屏幕标注”才会清除全部线条、图形和文字。

工具切换：`P` 画笔、`H` 荧光笔、`L` 直线、`A` 箭头、`R` 矩形、`O` 椭圆、`W` 波浪、`T` 文字、`E` 橡皮擦、`I` 人形标识、`C` 相机标识。相机标识会绘制镜头方向和取景视锥。

标识工具：第一次按下并拖动决定朝向；相机拖动距离决定取景范围长度。`V` 在俯视与立面之间切换，选中已有标识后按 `V` 可直接切换它。标识沿用当前颜色，可用小键盘 `0–9` 换色；使用对应工具再次拖动即可移动。

大小调节：`↑` 为 +1，`↓` 为 -1，`→` 为 +5，`←` 为 -5。橡皮擦实际宽度为显示大小的 4 倍。

小键盘颜色快捷键：`0` 黑、`1` 红、`2` 橙、`3` 黄、`4` 绿、`5` 青、`6` 蓝、`7` 紫、`8` 粉、`9` 白。

文字工具：切换到 `T` 后点击放置位置，会同时出现左侧输入框和右侧长期文字备案表。可将全部备用文案粘贴在右侧，从中复制词组或句子到左侧，按 `Enter` 确认放置，`Shift+Enter` 换行。右侧内容自动长期保存，只有主动删除才会清空。按住已有文字可移动，点击后可继续用方向键调整字号。
